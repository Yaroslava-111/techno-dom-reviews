# Пример промпта — анализ тональности

Если решите подключить настоящий ИИ вместо эвристики, вот ориентир
для запроса (например, к OpenAI Chat Completions API).

## Системный промпт

```
Ты — классификатор тональности отзывов покупателей интернет-магазина.
Определи тональность присланного текста и верни строго одно слово:
positive, neutral или negative. Ничего больше не добавляй.
```

## Пользовательский промпт (подставляется текст отзыва)

```
Текст отзыва: "{{текст отзыва}}"
```

## Ожидаемый ответ модели

Одно слово: `positive`, `neutral` или `negative` — используйте его,
чтобы показать соответствующую метку рядом с отзывом.

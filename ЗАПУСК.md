# Запуск стартового проекта

Форма отзывов интернет-магазина — без сервера и без сборки.

## Как запустить

Откройте `index.html` двойным щелчком (или File → Open в браузере).
Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`), запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Что нужно сделать

Базовая функциональность уже работает: форма добавляет отзыв в список,
список сохраняется в `localStorage`. Ваша задача — добавить **одну**
ИИ-функцию: анализ тональности текста отзыва (положительный /
нейтральный / отрицательный) и показать её рядом с каждым отзывом в
списке.

Место для реализации отмечено комментарием `// TODO:` в `script.js`,
функция `analyzeSentiment(text)` — сейчас она всегда возвращает
`"neutral"`, замените на реальный анализ.

Два допустимых уровня реализации:

1. **Простая эвристика** — без реального ИИ: по ключевым словам в
   тексте (например «отлично», «супер», «доволен» → положительный;
   «плохо», «ужасно», «не работает» → отрицательный; остальное —
   нейтральный). Подходит для самого простого решения.
2. **Вызов внешнего ИИ-API** — если хотите использовать настоящую
   модель, ориентир по переменным окружения — в `.env.example`, пример
   запроса — в `PROMPT_EXAMPLE.md`.

Отобразите тональность рядом с отзывом любым понятным способом —
цветной меткой, эмодзи или текстом («Тональность: положительная»).

Файлы:

- `index.html` — разметка экрана
- `style.css` — стили
- `script.js` — логика; функция `analyzeSentiment` — то, что нужно реализовать
- `.env.example` — переменные окружения для варианта с внешним API
- `PROMPT_EXAMPLE.md` — пример промпта для варианта с внешним API
